📋 How to Get Your JWT Token:

  1. Log into your Serenity Pocket app
  2. Open browser dev tools (F12)
  3. Go to Application → Local Storage
  4. Find your site's storage
  5. Look for keys like "auth_token", "sb-access-token", or similar
  6. Copy the token value (it's a long string)

🔍 Alternative: Test with Email

If you're logged in as info@playmindlabs.com or any @playmindlabs.com email, you should have admin access automatically.
